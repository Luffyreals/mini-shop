Cài đặt

Chạy trong 3 bước

Không cần cài Java, database hay Docker.

1

Tải bản Windows

Tải MiniShop-0.9.0-windows.zip ở trang Releases (~80 MB, Windows 10/11 64-bit).

2

Giải nén vào thư mục không dấu

Ví dụ C:\MiniShop. Đường dẫn có chữ ngoài bảng mã ANSI (ví dụ "ư") làm app thoát ngay.

3

Nhấp đúp MiniShop.exe

Windows SmartScreen có thể cảnh báo: bấm "Thông tin thêm" → "Vẫn chạy". Lần đầu app tự tạo dữ liệu mẫu.

.\mvnw.cmd javafx:run      # Windows PowerShell
Công nghệ

Bên trong Mini Shop

Stack thuần Java, không cần server bên ngoài. Gần 3000 test, CI fail nếu có test bị bỏ qua.

LớpCông nghệGhi chú
Ngôn ngữ Java 25 JDK 25 (Temurin)
Giao diện JavaFX 25 CSS của JavaFX, phông Plus Jakarta Sans
Nghiệp vụ Spring Boot 4.1 Data JPA, Validation, BCrypt — không có web server
Dữ liệu H2 Flyway H2 lưu ra file (chế độ tương thích PostgreSQL)
Kiểm thử JUnit Mockito TestFX ArchUnit ~3000 test; ArchUnit kiểm chiều phụ thuộc giữa module
Đóng gói jpackage MiniShop.exe + Java runtime riêng, chạy không cần cài Java
CI GitHub Actions Build, test, đóng gói Windows, upload artifact
