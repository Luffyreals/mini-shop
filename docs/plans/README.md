# Kế hoạch theo giai đoạn

Mỗi giai đoạn có một file `phase-<N>.md` do subagent `tech-lead` lập **từ spec đã duyệt** trong [`docs/specs/`](../specs/README.md), và người dùng duyệt trước khi triển khai. Mỗi task ghi rõ những tiêu chí `AC-…` mà nó đáp ứng. Mỗi file gồm: mục tiêu, quyết định thiết kế, danh sách task (agent phụ trách, file, phụ thuộc, điều kiện "xong"), checklist kiểm tra cuối giai đoạn, và câu hỏi cho người dùng.

Lộ trình tổng thể nằm ở mục 11 của [project-brief.md](../project-brief.md).
